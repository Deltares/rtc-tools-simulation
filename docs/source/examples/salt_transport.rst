Salt Examples
=============

This section contains examples of modelling salt transport
using the :py:class:`SaltSimulationMixin` class documented in :ref:`zsf_connection`.

We recommend to start with :ref:`examples-salt-transport-basic`,
which describes how to build a simple reservoir model step by step.
Other examples showcase applications of different schemes.
